Privacy Policy

Last updated: November 4, 2026

This policy describes how Calm Flow Pipeline (the "App") handles data. The App is a private automation operated by the owner of the Calm Flow Audio YouTube channel to publish that channel's own videos. It is not a public service and is used by a single account.

Data the App accesses

With the channel owner's authorization via Google OAuth, the App uses the YouTube Data API to:

  • upload videos and their titles, descriptions and tags to the owner's channel (youtube.upload scope);
  • set custom thumbnails on those videos and read basic channel information to confirm the connected channel (youtube scope).

The App does not read, collect or process data from any other YouTube user or Google account.

How data is stored

OAuth credentials (client ID, client secret and refresh token) are stored only in a local configuration file on the owner's own computer or server. They are never sent to any party other than Google's OAuth and YouTube API endpoints. Video, audio and image files are generated locally and deleted after a successful upload.

Sharing

The App does not sell, rent, share or transfer Google user data to anyone. No Google user data is used for advertising, analytics or to train AI/ML models.

Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The App also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions or via the Google security settings page. Revoking access invalidates the stored refresh token; the local configuration file can then be deleted to remove all stored credentials.
