Como Publicar Sua Biblioteca Go no Pkg Go

31 out. 2024 · 2 min de leitura
Sumário

Continuando minha jornada para aprender Go com profundidade, hoje vou mostrar como publicar sua biblioteca no Pkg.Go.

Antes de tudo, você precisa ter uma biblioteca Go na sua conta do GitHub ou em qualquer outro repositório Git. Neste exemplo, vou usar uma biblioteca simples que criei, para mostrar como publicá-la.

A biblioteca é a valid-brazilian-cnpj. No Brasil temos um documento chamado CNPJ, e no ano que vem as regras de validação vão mudar, então criei esta biblioteca para me ajudar a validar CNPJs.

Como criei a biblioteca não é o foco deste post, mas, se quiser ver o código, é só acessar o repositório.

Para publicar sua biblioteca no Pkg.Go, você precisa criar uma release no seu repositório.

Primeiro passo: rode go mod tidy

O primeiro passo é rodar go mod tidy para garantir que todas as dependências estejam no arquivo go.mod.

go mod tidy

Segundo passo: rode os testes

O segundo passo é rodar os testes para garantir que tudo funciona como esperado.

go test -v

Esse comando roda todos os testes da biblioteca e mostra os resultados.

Terceiro passo: crie uma tag

O terceiro passo é criar uma tag no seu repositório.

git tag v0.1.0
git push origin v0.1.0

Esses comandos criam uma tag chamada v0.1.0 e a enviam para o repositório.

Quarto passo: envie para o Pkg.Go

GOPROXY=proxy.golang.org go list -m github.com/linuxsoares/valid-brazilian-cnpj@v0.1.1

Explicando o comando:

  • GOPROXY=proxy.golang.org: é a URL do Pkg.Go
  • go list -m github.com/linuxsoares/valid-brazilian-cnpj@v0.1.1: este comando envia a biblioteca para o Pkg.Go

Depois de rodar esse comando, você já pode acessar a biblioteca no Pkg.Go.

Conclusão

Neste post, mostrei como publicar sua biblioteca no Pkg.Go. É um processo simples, mas é importante seguir os passos para garantir que tudo funcione como esperado.

Espero que você tenha gostado deste post, e até o próximo.
