Por anos, o tmux foi o rei absoluto do meu fluxo de trabalho no terminal. Ele mantinha minhas sessões vivas, me deixava gerenciar abas e dividir painéis sem esforço. Mas, conforme agentes de código com IA como Claude Code e Antigravity passaram a fazer parte do meu dia a dia de desenvolvimento, senti falta de um gerenciador de workspaces que entendesse esses agentes.

É aí que entra o Herdr, um gerenciador de workspaces nativo do terminal, feito especificamente para desenvolvedores que trabalham junto com agentes de código com IA. Ele oferece sessões persistentes, isolamento de workspaces e acompanhamento nativo do status dos agentes.

Mas trocar de ferramenta não deveria significar jogar fora anos de memória muscular. Veja como configurei o Herdr para se comportar exatamente como meu tmux, dos atalhos ao tema.

A configuração: mapeando o tmux para o Herdr

A configuração do Herdr fica em um arquivo TOML simples, em ~/.config/herdr/config.toml. Para alinhá-lo às minhas convenções do tmux, mapeei as teclas na seção [keys].

1. A tecla de prefixo

Por padrão, o Herdr usa ctrl+b. Assim como no meu .tmux.conf, remapeei para ctrl+a:

[keys]
prefix = "ctrl+a"

2. Dividindo painéis de forma visual

Prefiro usar | para dividir painéis na vertical (lado a lado) e - para divisões horizontais (um em cima do outro), porque são muito mais fáceis de lembrar que os padrões:

split_vertical = "prefix+|"
split_horizontal = "prefix+minus"

3. Navegação entre painéis e abas

Para me mover rápido sem interromper o fluxo, configurei uma combinação de setas e atalhos diretos:

  • Troca de painel: foco nos painéis usando as setas com o prefixo (ctrl-a + Cima/Baixo/Esquerda/Direita): 
    focus_pane_left = "prefix+left"
focus_pane_down = "prefix+down"
focus_pane_up = "prefix+up"
focus_pane_right = "prefix+right"
  • Troca direta de abas: atalhos diretos, como os do sistema operacional, para alternar entre abas sem apertar o prefixo: 
    previous_tab = "ctrl+alt+h"
next_tab = "ctrl+alt+l"

4. Listas interativas (o equivalente ao choose-tree)

No tmux, prefix + w abre uma lista de sessões e janelas (choose-tree). No Herdr, a busca equivalente é o goto. Troquei as teclas padrão para mapear o goto para o meu atalho do tmux:

goto = "prefix+w"
workspace_picker = "prefix+g"

Agora ctrl-a + w abre uma busca em todos os workspaces, abas e painéis ativos.

5. Gerenciando workspaces na hora

Renomear workspaces ajuda a manter meus projetos ativos organizados. Ativei o atalho interativo para renomear workspaces:

rename_workspace = "prefix+shift+w"

Com ctrl-a + W, ele pede um novo nome para o workspace ativo.

6. Recarregando a configuração

Para testar mudanças de configuração sem parar o servidor, mapeei o comando de recarregar:

reload_config = "prefix+r"
resize_mode = "prefix+shift+r" # Shifted resize_mode to avoid conflicts

Harmonia visual: levando o tema Nord para o Herdr

Uma das coisas de que eu mais gostava no tmux era meu tema Nord. Felizmente, o Herdr já vem com um tema Nord embutido. Configurar foi tão simples quanto mudar uma linha no bloco [theme]:

[theme]
name = "nord"

Isso atualiza as bordas, a barra de status, os destaques e os menus de busca para combinar com a estética limpa e gelada do Nord.

O veredito

Trocar o tmux pelo Herdr não exigiu sacrificar meu fluxo de trabalho. Mapeando as configurações no config.toml, fiquei com o melhor dos dois mundos:

  1. Minha memória muscular continua intacta.
  2. Agora tenho um gerenciador de workspaces que acompanha nativamente meus agentes de código com IA, roda esses agentes em sessões persistentes em segundo plano e se integra perfeitamente ao meu terminal.

Se você quer atualizar seu multitarefa no terminal para a era da IA, recomendo muito experimentar o Herdr!
